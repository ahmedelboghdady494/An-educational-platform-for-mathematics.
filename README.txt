An Educational Platform for Mathematics — Grade 9 Advanced

This package includes:
- index.html
- 69 lesson PDFs already prepared in files/
- Term 1 worksheet source DOCX
- Source-based worksheet question data and equation images
- Demo login: clicking Google Login opens the student profile form without Supabase

Upload instructions:
1. Open your GitHub repository.
2. Add/Upload all files and folders from this package.
3. Keep the files/ folder, worksheet_assets/ folder, index.html, and worksheet_data.js in the same repository root.
4. Commit changes.
5. GitHub Pages will update after the commit.
