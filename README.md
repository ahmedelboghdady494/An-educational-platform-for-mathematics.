An Educational Platform for Mathematics — Grade 9 Advanced (UAE)

This package keeps the existing Term 1 lessons, quizzes, challenges, progress system, and lesson PDFs, while adding:
- Light, comfortable visual theme
- Student onboarding form matching the supplied screenshot
- Prepared Google sign-in flow using Supabase Authentication
- Separate Math World section that evolves with completed learning activity
- Achievements page based only on actual completed quizzes/challenges
- New site branding: An Educational Platform for Mathematics

IMPORTANT — Google login
The HTML contains placeholders:
SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL_HERE"
SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE"

The real Google button will work after a free Supabase project is created, Google provider is enabled, and these two values are added to index.html. The GitHub Pages URL must also be added as an allowed redirect URL in Supabase.
